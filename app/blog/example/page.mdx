# Example MDX Blog Post

This is a sample blog post written in MDX to demonstrate the setup.

## What is MDX?

MDX allows you to use JSX in your markdown content. You can import components and embed them directly in your markdown.

### Key Features

- **Write in Markdown**: Use familiar Markdown syntax
- **Embed React Components**: Import and use React components
- **Type-safe**: Full TypeScript support
- **Fast**: Built on top of Next.js for optimal performance
